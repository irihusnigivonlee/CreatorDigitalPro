# CreatorDigitalPro Auth Gate + Navbar Login Register

Patch ini menambahkan:

- Tombol **Login Demo** dan **Daftar Gratis** di navbar homepage.
- Popup elegan saat user menekan Download/Export sebelum login.
- Tombol menuju halaman `pages/login.html` dan `pages/register.html` dengan parameter `next` agar kembali ke halaman tool.
- Login cepat demo menggunakan localStorage.
- Status demo user + tombol logout.
- Watermark tetap aktif pada export/download mode demo.

Catatan: ini proteksi demo GitHub Pages. Untuk production wajib memakai backend PHP/database/license.
