# 3D Ebook Cover Generator - CreatorDigitalPro

Letakkan semua file ini di:

`tools/ebook-3d-generator/`

Cara buka lokal:

```bash
php -S localhost:8000
```

Lalu buka:

`http://localhost:8000/tools/ebook-3d-generator/`

Fitur:
- Landing super elegan
- Three.js live preview
- Upload cover ebook
- Pilihan model Standing, Box, Tablet, Flat
- Kontrol rotate, zoom, background
- Download PNG
