# CreatorDigitalPro Intro Studio Pro v2.0

Isi ZIP ini bisa ditimpa ke folder lama Intro Video Maker.

Fitur:
- 5 template intro video: Creator Classic, Gaming Neon, Business Elite, Breaking News, Islamic Premium.
- Upload logo, background, dan musik.
- Ganti judul, tagline, warna judul, warna subtitle, warna tema.
- Preview canvas 1920x1080.
- Export PNG dan WEBM.
- Path aman untuk GitHub Pages.

Cara pasang:
1. Extract ZIP ini.
2. Copy seluruh isi ZIP ke folder lama `tools/intro-video-maker/`.
3. Pilih Replace/Timpa.
4. Push ulang ke GitHub.
