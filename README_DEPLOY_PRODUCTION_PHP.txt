CreatorDigitalPro - Production PHP Clean

Paket ini untuk hosting PHP seperti Hostinger, Niagahoster, Rumahweb, cPanel, atau VPS.
Yang sudah dibersihkan:
- .git dihapus
- .env asli dihapus
- backup zip dihapus
- package-lock.json dihapus
- file produk private tidak disertakan agar aman

Langkah sebelum live:
1. Rename .env.example menjadi .env lalu isi MIDTRANS_SERVER_KEY dan MIDTRANS_CLIENT_KEY.
2. Upload ZIP produk final ke private/downloads/CreatorDigitalPro_Product.zip.
3. Pastikan folder storage/ writable.
4. Isi link YouTube/Telegram di index.html.
5. Untuk penjualan serius, pindahkan order storage dari JSON ke database.
